# Changelog

**Releases are tracked on GitHub, not in this file:
[github.com/PiotrRomanczuk/strummy/releases](https://github.com/PiotrRomanczuk/strummy/releases)**

Each merge to `main` cuts an annotated tag and a GitHub Release whose notes are the PR
description, so the release history is generated from the work rather than transcribed after it.
182 releases exist as of 2026-07-27.

## Why this file stopped

Hand-maintained changelogs drift the moment releasing is automated. This one froze at **0.65.0
(2026-02-09)** while the project went on to **0.160.0** — ninety-five versions of silence, which
is worse than no file at all because it looks authoritative.

Entries below 0.65.0 are kept as a historical record of the period when the changelog was
maintained by hand. Do not add to them.
