Manual test — Strummy brand "pick" mark

Date: 2026-08-06

What changed

Implemented the finalized Strummy brand identity from Claude Design (project "Strummy", file Strummy - Logo Final (The Pick).html): a guitar-pick-shaped mark with three "strum" lines inside it, in the brand gold #b17f12.

  • New shared component components/shared/BrandMark.tsx (PickMark) — a single inline SVG that themes itself via the existing --gold-2 CSS token, with a hardcoded fallback for places outside the .theme-strummy scope.
  • Landing page Wordmark (nav + footer) now shows the pick mark instead of a plain gold dot.
  • Dashboard sidebar (desktop + mobile sheet) and the peripheral-page nav shell now show the pick mark instead of a lucide "Guitar" icon in a hardcoded orange gradient circle.
  • Browser tab favicon now uses the design's dedicated favicon SVGs (public/favicon-light.svg / favicon-dark.svg, rounded-square tile, switches with OS/browser color scheme via prefers-color-scheme).
  • public/manifest.json theme_color updated from the old orange #e89215 to brand gold #b17f12.

Not done: the 192×192 / 512×512 PWA icon PNGs in public/icons/ still show the old mark — regenerating them needs raster/image-export tooling not available in this session. Follow-up.

How to test

  1. Run npm run dev and open http://localhost:3000.
  2. Landing page (/): the pick mark should appear immediately before "Strummy" in the top nav, and again (larger) in the footer.
  3. Dashboard: sign in, go to /dashboard. The sidebar header (top-left) should show the pick mark in a soft badge instead of the old orange-circle guitar icon. Shrink the window below the md breakpoint and open the hamburger menu — the mobile sheet header should match.
  4. Dark mode: toggle the theme switch (dashboard) and confirm the mark stays legible — gold accent adapts via the existing token cascade.
  5. Favicon: check the browser tab icon. Toggle your OS/browser color scheme (System Settings → Appearance, or DevTools → Rendering → prefers-color-scheme) and reload — the tab icon should switch between the light (cream tile) and dark (ink tile) versions.
  6. Peripheral pages (/onboarding, /ai if reachable): confirm the nav shell header also shows the new mark, not the old icon.

Automated coverage

Existing unit suites for the touched components already assert on structure/text, not the icon markup, and pass unchanged: components/dashboard/sidebar/*.test.tsx, __tests__/components/navigation/menuConfig.test.ts. No new Playwright spec was added — this is a static visual/asset swap with no new interactive behavior.
