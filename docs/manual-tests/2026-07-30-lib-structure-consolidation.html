What was actually done

Almost all of this is file moves and deletions with no runtime behaviour change. There is exactly one visual change, called out below. 119 files changed, −3,227 lines.

The part that was not cosmetic

Four lib/ names existed as both a file and a directory (config, logger, supabase, utils). In module resolution the file wins — so lib/supabase.ts was silently making lib/supabase/index.ts unreachable. That shadowed barrel exported a second authenticateRequest with a different signature from the live one in lib/auth/api-auth.ts, and pulled in next/headers, which would have broken the client bundle had anyone ever reached it.

Each colliding file is now its directory's index.ts, so every existing @/lib/<name> import resolves unchanged — 270 @/lib/logger imports did not move.
