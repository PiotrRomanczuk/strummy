Lab — strona utworu i karta na stronie Strummy (SNG-11, część 2b)

2026-11-13 · gałąź feature/lab-song-page

Co zrobione

  • Utwór (/dashboard/admin/lab/songs/[id]): wszystkie wiersze wszystkich źródeł obok siebie, w kolejności z manifestu. Czytelne widoki: akordy Chord ID na osi czasu (powtórzony akord raz), arkusze Chordonomiconu po częściach („Fsmin” → „F#m”), akordy z projektu Logica, opis McGill do rozwinięcia; reszta jako pola, a cały wiersz w JSON. Linki: utwór w Strummy, Spotify, YouTube.
  • Strona utworu Strummy: karta „Lab” (tylko admin, tylko gdy hub jest na tym Macu): w ilu źródłach jest utwór, ile ma tabów, link do Lab. Karty admina (jakość danych + Lab) zebrane w jeden slot admin, więc SongDetail nie rośnie.
  • Id encji sprawdzane wyrażeniem ^e[0-9a-f]{12}$ przed zbudowaniem ścieżki pliku.

Jak przetestować

  1. Jak w części 2a; z listy utworów otwórz utwór z polubionych z Chord ID i Chordonomiconem → oś akordów, arkusz po częściach, porównanie.
  2. Otwórz utwór Strummy, który jest w hubie → w prawej kolumnie karta „Lab” → link do utworu w Lab.
  3. Nauczyciel/uczeń: brak karty; bez PRIVATE_DATA_DIR: brak karty, Lab = „nie znaleziono”.
  4. Zmyślone id (/dashboard/admin/lab/songs/enotanentity) → „nie znaleziono”.
