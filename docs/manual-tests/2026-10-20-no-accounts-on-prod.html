What was done

Every signed-in E2E run now belongs to the dev stack. playwright.prod.config.ts calls assertNoRoleAccountsForProduction(baseURL) (new, in tests/helpers/deployed-target.ts): when the target is strummy.online / strummy.vercel.app and any TEST_*_EMAIL is a real address (not the @dev.local placeholder), the config throws before a single spec loads. E2E_ALLOW_PROD_ACCOUNTS=1 is the explicit override. Docs (CLAUDE.md, tests/README.md) describe the new rule: against production only --grep @smoke with E2E_SKIP_AUTH_PREFLIGHT=1.
