Manual Test Report: Skills Checklist by Level

feature/skills-checklist-by-level

What was done

The existing Skills tracking feature (skills catalog + student_skills per-student assessment, already shipped before this change) is extended with a beginner / intermediate / advanced level dimension, matching the curriculum tiers a guitar teacher actually uses (open chords & basic strumming → barre chords, CAGED, theory basics → fingerstyle, advanced technique).

  • Migration adds skills.level (beginner/intermediate/advanced, checked), backfills all 72 existing catalog rows, and inserts 4 new skills that were genuine gaps: barre-chord construction, reducing a song to its relative-minor/CAGED family, thumb-over-barre fingerstyle, and the boom-chick bass/strum pattern.
  • The Skills tab on the student detail page (components/users/StudentDetail.Skills.tsx) is rebuilt as a real per-level checklist: every catalog skill for the active level is always shown (not just previously-assigned ones), with a status control per row. Picking a status is what assigns the skill — there's no more separate "Assign New Skill" dropdown.
  • Each level tab shows a live progress count, e.g. Beginner — 1/15 mastered, that updates immediately after a status change.
  • Admin/teacher get an editable status <select> per skill; students see the same full checklist read-only.
  • The previously hardcoded "Skills" tab label (no translation key existed) is fixed — it now uses a real detailTabSkills i18n key, mirrored in English and Polish, along with all new level/status/progress strings.
  • Input validation for the skill-update server action was upgraded to a Zod schema (schemas/StudentSkillSchema.ts), matching the validation standard already used by the Repertoire feature.

How to manually test it

Setup: npm run dev, sign in via the Dev Quick Login panel at /sign-in (Admin / Teacher / Student). Open any student's detail page and click the Skills tab.
