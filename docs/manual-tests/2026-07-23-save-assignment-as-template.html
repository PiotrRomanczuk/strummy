Save an assignment as a template

2026-07-23 · branch feature/save-assignment-as-template · Strummy — Assignments

What this adds

Strummy already lets a teacher start a new assignment from a saved template (the "Start from template" picker). This change adds the reverse direction — turning an assignment you've already made into a reusable template — in two places:

Surface 1 Assignment detail page — a "Save as template" button next to Edit (teacher/admin only). One click copies the assignment's title, brief, and checklist into a new template, then the button becomes "Saved ✓ View template" linking straight to it.

Surface 2 New assignment form — an "Also save this as a reusable template" checkbox above the Create button (create mode only). When ticked, submitting creates the assignment and a matching template in one go.

Both surfaces call one server action, saveAssignmentAsTemplate(assignmentId), which reads the assignment server-side (RLS-scoped, respecting soft-delete) so the copy is authoritative rather than client-supplied. Checklist items are copied unchecked (a template seeds fresh work), and the template's owner is always forced to the current user. No database migration is needed — the assignment_templates table already stores exactly these fields.

How to test manually

Setup: npm run dev, sign in as the admin/teacher (p.romanczuk@gmail.com), and have at least one assignment created.

Surface 1 — detail-page button

  1. Open an existing assignment: /dashboard/assignments/<id>.
  2. In the header row you should see Save as template to the left of Edit.
  3. Click it. Expect: it briefly shows "Saving…", then becomes "Saved ✓ View template".
  4. Click "View template". Expect: you land on the template edit page with the assignment's title, brief, and an unchecked copy of its checklist prefilled.
  5. Go to /dashboard/assignments/templates. Expect: the new template appears at the top of the list, with its checklist-item count.

Surface 2 — create-form checkbox

  1. Open /dashboard/assignments/new.
  2. Fill in a student, title, brief, and (optionally) a checklist.
  3. Tick "Also save this as a reusable template", then click Create assignment.
  4. Expect: you're taken to the new assignment's detail page as usual…
  5. …and /dashboard/assignments/templates now also has a matching template.
  6. Repeat without ticking the box. Expect: the assignment is created but no new template appears.

Edge cases worth checking

  • Student view: a student opening an assignment detail sees no "Save as template" button (teacher/admin only).
  • Checklist reset: assign homework, tick some checklist items as done, then Save as template — the template's items should all be unchecked.
  • Best-effort on create: the template copy on the create form is non-blocking — if the template write were to fail, the assignment is still created and you still navigate to it (the checkbox never blocks the primary action).
  • Templates unaffected downstream: deleting the created template later does not touch the assignment it came from.
