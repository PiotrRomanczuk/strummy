Onboarding — “what do you play?”

Date: 2026-07-29 · Branch: feature/onboarding-guitar-type

What was actually done

Onboarding now asks both roles which instruments they actually have. Multi-select, and skippable.

Experience level was already captured and was not rebuilt. Students have picked a four-way skill level (New to guitar / A few months in / Confident / Many years in) since the wizard shipped; it persists to profiles.skill_level and already showed on the teacher's student page. Only the instrument question was missing.
Piece Detail
Where it's asked Student: inside the existing “Your guitar journey” step. Teacher: inside “About you”. No new screen was added — the student flow stays three screens, which is what keeps completion high.
Options Acoustic (steel-string), Classical (nylon), Electric, Bass, Ukulele, I don't have one yet.
“I don't have one yet” Mutually exclusive in both directions: picking it clears the instruments, picking an instrument clears it. Without that you can end up telling the teacher “electric, and no guitar yet”.
Storage user_preferences.instrument_preference — an array column that already existed, fully migrated and under RLS, but which nothing in the codebase read or wrote. No migration was needed.
Teacher semantics Distinct from the two existing teacher fields: instrument (their single primary, free text) and teaches (styles they take students for). A teacher can own an electric and still only teach classical.
Where it shows The teacher's student-detail “about this student” line, beside skill level and goals — rendered as prose (Acoustic (steel-string)), not storage keys.

How to manually test

1. Student path

  1. Sign up a fresh account (or clear onboarding_completed on a test profile) and reach /onboarding.
  2. Choose I want to learn → Continue. The journey step now has “What are you playing on?” marked optional.
  3. Pick a goal only, and confirm Finish setup is already enabled — the instrument question must never gate the step.
  4. Select Acoustic and Electric; then click I don't have one yet and confirm the other two clear. Click Bass and confirm “none” clears.
  5. Finish, then open that student from a teacher account: the chips appear on the about line in readable form.

2. Teacher path

  1. Onboard as a teacher; the About you step has the same question below name / years teaching.
  2. Pick one or two, finish the wizard, then verify persistence:
docker exec supabase_db_StudentDevelopment psql -U postgres -d postgres \
  -c "SELECT p.email, up.instrument_preference
      FROM user_preferences up JOIN profiles p ON p.id = up.user_id
      ORDER BY up.updated_at DESC LIMIT 5;"

3. Backwards compatibility

Anyone who onboarded before this change has no instrument_preference row value. Open their student page and confirm the about line renders exactly as before, with no empty placeholder and no crash.

Known limitation

A teacher's own instruments are stored but not yet displayed anywhere — their settings page has no “about you” surface to hang them on. Student instruments, the high-value direction, are displayed. Worth a follow-up if teacher profiles ever grow a public face.
