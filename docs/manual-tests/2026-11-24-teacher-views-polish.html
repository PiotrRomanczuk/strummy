How to test manually

  1. Sign in as the dev teacher, add a student at /dashboard/users/new, open the card: badge is "On track" / "W normie", no banner. Add ?lang=pl to switch language.
  2. /dashboard/assignments/new: click the song field, type "wond": the list narrows; pick one. Same on /dashboard/assignments (quick assign) and on a lesson page ("+ Add song").
  3. /dashboard/songs/requests: no request shows "Unknown student"; a request from a real student shows the name and a locale date.
  4. Compare the bell label with the count on /dashboard/notifications.
  5. /dashboard/admin/lab as teacher: dashboard shows the notice; the cross removes it and the error parameter.
  6. /dashboard/settings?tab=apiKeys: one title, one description, no "Guitar CRM".
