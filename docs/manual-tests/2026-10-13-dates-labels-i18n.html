Dates, statuses and labels in the viewer's language

2026-10-13 · branch fix/walkthrough-review-6-dates-labels-i18n

What changed

  • Calendar month title follows the locale ("Październik 2026").
  • Assignment detail: due date and lesson date localized, "View history" and the submission type translated (the English label map in the schema is gone; the create form's keys are reused).
  • Student profile and list: dates localized through one shared formatter; the health badge ("W normie" / "Wymaga uwagi" / "Zagrożony") and the lesson-history status are translated.
  • Add/edit student: instrument names and the four levels translated; levels now sit in a 2×2 grid so none is clipped.
  • Repertoire row date localized with the next-intl locale, which is identical on server and client (the hydration warning in that file still holds).

How to test

  1. Demo teacher, Polish, 390 px. /dashboard/calendar: month title "Październik 2026".
  2. /dashboard/assignments → open the overdue worksheet: "termin niedziela, 11 października 2026", "Historia zmian", "Sposób zaliczenia · Zgłoszenie własne".
  3. /dashboard/users: join dates like "27 sie 2026". Open Zofia: badge "W normie", "Od 27 sie 2026"; Lessons tab rows end in "Zakończona".
  4. /dashboard/users/new: instrument "Gitara", levels Początkujący / Nowicjusz / Średnio zaawansowany / Zaawansowany, none truncated; saving stores the same English values as before.
  5. Demo student /dashboard/repertoire: dates like "13 paź 2026".
  6. Switch to English: everything as before.
