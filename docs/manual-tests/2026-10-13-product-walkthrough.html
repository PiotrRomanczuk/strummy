Product walkthrough — „Strummy · Przewodnik po ekranach”

Date: 2026-10-13 · Branch: docs/product-walkthrough · Scope: docs tooling + generated PDF, no app code changes

1. What was done

A Polish, 38-page A4 PDF modelled on the Softfruit.farm „dokumentacja dla sprzedaży” format: cover with chapter list and status box, a product chapter (for whom / what you get / what is deliberately missing / the core loop), twelve screen chapters where each screen gets a phone shot and three blocks — Co widać · Po co · Dla sprzedaży — plus an Uwaga line wherever a real gap is visible (English hard-coded strings, demo-data holes, the raw GoTrue invite template), then desktop/tablet, eight design principles, FAQ and a glossary.

  • Screens are real, captured from the dev stack with Playwright (tests/e2e/manual/product-walkthrough.spec.ts + a shot table), as the Polish demo studio (Anna Kowalska / Zofia Nowak), at 390×844 @2× for phone, 1440×900 desktop, two tablet sizes. Dev-only chrome (Next.js badge, DB indicator, quick-login) is stripped before each shot. 75 shots; 55 are used by the document.
  • Content is TypeScript (docs/product-walkthrough/content/NN-*.ts), one chapter per file, written after looking at every shot.
  • Build (scripts/docs/walkthrough/build.ts) inlines JPEGs, renders HTML with the project's ivory/ink/gold tokens and prints A4 through Playwright's Chromium. WebP was tried first and rejected: Chromium decodes it to raw bitmaps inside the PDF (15 MB); JPEG streams are embedded as-is (8 MB).
  • Side fixes: seed-demo.ts now pages through auth.admin.listUsers (the dev stack has 5 443 accounts from the flows suite, so the single 1 000-row page could not find the demo teacher); settle() in tests/helpers/screenshot.ts is exported for reuse.
