Song analyses backfill — manual test

Date: 2026-11-10 · Branch: feature/song-analyses · Tested on: local Supabase stack on the Mac (copy of production data from 2026-11-10). Not applied to dev or production.

What was done

  • New table song_analyses (migration 20261110120000_song_analyses.sql): one row per song with what song2logic heard in the recording: tempo, metre, key, main chords, tuning, the full analysis JSON, and filled_fields. Staff can read it; only the service role writes.
  • New script scripts/backfill/2026-11-song-analyses.ts: loads a song2logic batch run into that table and fills only empty tempo, time_signature, chords and youtube_url on songs. key is never written; the row records whether the detected key is the same, relative or different.
  • Nothing is filled unless the analysed recording is as long as the song's Spotify duration (4 % or 6 s). Tempo is skipped when the beat tracker rejected many double beats; metre is skipped when bars came out as two beats.
  • No UI reads the table yet.

4 Run --commit with NEXT_PUBLIC_SUPABASE_URL pointing at a non-local host and no --remote "Refusing to write to … without --remote", exit code 2. Checked by reading the code only, not run.
5 Read the 22 filled chord lists against songs you know Open-chord songs look right (Fake Plastic Trees: A, Bm, D, F#m). Riff songs are wrong or padded (Back in Black: A, Bm, E, D, C#m, G). Decide whether chords should be filled automatically at all.

Known limits

  • The migration is applied only to the local stack. database.types.ts already includes the table, so the types-drift check fails until dev has it; dev and production must get it together, or the dev-equals-production schema check fails.
  • 31 of 72 keys disagree. 11 of those songs have key = C stored, and 136 of 384 keyed songs in production have C, which looks like a default rather than a fact. The detector is also wrong on its own in roughly a third of songs.
  • Chords are triads only, so power-chord riffs come out as invented major and minor chords.
  • The Spotify duration check passes any recording of the right length, including a cover.
