Anonymisation for the StrummyTest copy of production

Date: 2026-11-15 · Scope: scripts/test-stack/ (rules, SQL generator, auth part, CI check)

What was done

  • anonymize.rules.json classifies every column of all 62 public tables (audit partitions follow audit_log). Free text becomes Lorem ipsum of the same length, addresses become …@test.strummy.invalid, names become Uczeń 1A2B-style labels, credentials/tokens/logs/leads are deleted.
  • anonymize-auth.sql: every account keeps its id, gets a test address and the shared test password (passed as a psql variable, never stored), one email identity, no sessions/tokens/MFA. A final block aborts the whole transaction if any real address, phone, credential or transcript share link survives.
  • Runs in one transaction with triggers off (session_replication_role = replica), so no audit row keeps the old values.
  • anonymize.unit.test.ts reads database.types.ts: a new column without a rule fails CI.
  • Not built yet: the StrummyTest stack and its weekly refresh (part B, on uwh, with the owner).
