Fretboard: accessibility, full E2E coverage, scale formula

2026-08-04 · components/fretboard/, lib/music-theory/, tests/e2e/{teacher,student}/fretboard.spec.ts

What changed

  • Removed a dead inline <style> media query in Fretboard.tsx that targeted a nonexistent class (.fb-layout) — the real mobile collapse already lives in app/design-tokens.css's .ui-fret-layout rule.
  • Added aria-pressed to the mode/key/accidental chip buttons and aria-labels to the scale/chord <select>s.
  • Added a per-cell aria-label (note, root flag, string, fret) to all 72 board cells, and made hidden (non-scale) cells non-focusable (tabindex="-1", aria-hidden) when "Hide non-scale notes" is on.
  • Added .ui-fb-chip / .ui-fb-cell hover and focus-visible states to app/design-tokens.css, following the existing .ui-chip/.ui-row pattern — inline styles alone can't express :hover/:focus-visible.
  • New: the info panel now shows a Formula section for the selected scale — the interval formula (e.g. R – 2 – 3 – 4 – 5 – 6 – 7) and the whole/half-step pattern (e.g. W-W-H-W-W-W-H), computed live from the scale's existing interval data via a new getScaleStepFormula() helper — no new content authoring required.
  • Fixed doc drift in docs/app-blueprint/05-chords-theory.md: it said fretboard was nav-hidden; it's been nav-visible (teacher 2026-07-19, student 2026-08-01) for two weeks.
  • New E2E file: tests/e2e/student/fretboard.spec.ts — closes the mandatory Admin/Teacher/Student POV gap.
  • Extended tests/e2e/teacher/fretboard.spec.ts with keyboard, malformed-URL, extra-chord-type, accessible-name, and scale-formula tests.

How to manually test

  1. Prerequisites: dev stack running (npm run dev), logged in as any role (teacher or student both work — the page is identical).
  2. Go to /dashboard/fretboard.
  3. Keyboard/a11y: click into the page, then press Tab repeatedly. You should see a visible gold focus ring on chip buttons and board cells (previously none was visible). Tab to the "Chord" mode button and press Enter — mode switches and the chord dropdown appears. Tab to a key letter and press Space — the root moves.
  4. Hover: mouse over any chip button or fretboard cell — a subtle highlight now appears (previously nothing happened on hover besides the cursor).
  5. Screen reader (VoiceOver: Cmd+F5): turn on "Show intervals", then tab through board cells — you should hear e.g. "A, root note, string 1 fret 5" instead of just "R".
  6. Scale formula: with Mode = Scale, pick different scales from the dropdown (Major, Pentatonic Minor, Blues, …) and watch the new "Formula" section between the note chips and the "About" text — it should show the interval formula and W/H step pattern, updating live as you change scale.
  7. Edge case: navigate directly to /dashboard/fretboard?key=zz&mode=bogus&scale=nope — it should silently fall back to the default A Pentatonic Minor view instead of erroring.
