Conflicts that needed judgement (not mechanical)

  • proxy.ts — main's profile-id fix (.eq('user_id', …) + fail-closed on a broken profile lookup) was kept, and the i18n branch's locale resolution (cookie → Accept-Language → DB preference) was kept alongside it. Both survive.
  • UsersList.tsx / InlineInviteButton.tsx — the resend-invite feature (#612) and the i18n rewrite hit the same lines. Combined: translated labels and resend behaviour. A new key Users.inviteInlineResendButtonLabel replaces the hardcoded "Resend invite →".
  • StudentDetail.Header — the i18n branch split it into StudentDetail.Header.Identity.tsx; that split was kept and main's "already invited, never signed in → resend" action was grafted into the new component.
  • Theory components — the i18n branch translated three files (TheoryChapterReader/TheoryCourseCard/TheoryCourseForm) that the structural branch deletes as dead code (no page imports them; the live ones came from components/v2/theory). The deletion was kept and the translations were re-applied to the live components, so no i18n work was lost. Polish chapter/course counts now use ICU plurals (1 rozdział / 2 rozdziały / 5 rozdziałów), which the old singular/plural key pair got wrong.
  • components/navigation/Header.tsx — git could not see this as a rename (the destination path was already occupied), so the i18n role-label translation was ported by hand.

How to manually test it

Setup

git checkout chore/integrate-three-features
npm install          # next-intl arrives with the i18n branch
npm run dev          # http://localhost:3000

Sign in with the dev role accounts from CLAUDE.local.md (email/password — Google SSO does not work against the LAN dev stack).

A. Polish localization

  1. Open the app with an English browser profile.
    Everything renders in English; no raw keys like Theory.courseListTitle appear.
  2. Switch language with the toggle in the header (or set the NEXT_LOCALE cookie to pl and reload).
    UI flips to Polish and the choice persists across a full reload — the proxy writes the cookie back.
  3. Visit /dashboard/theory on desktop and at a mobile width (<768px).
    Header reads Nauka / Teoria; the count line uses correct Polish plurals — check with 1, 2 and 5 courses: 1 dostępny kurs, 2 dostępne kursy, 5 dostępnych kursów. Level chips read Początkujący / Średnio zaawansowany / Zaawansowany, not the raw DB value.
  4. Open a course chapter (/dashboard/theory/<courseId>/<lessonId>).
    Breadcrumb says Teoria; the "last updated" line reads Ostatnia aktualizacja: …. Chapter counts on the course cards read 1 rozdział / 2 rozdziały / 5 rozdziałów.
  5. As a teacher/admin, create a course via /dashboard/theory/new, then edit it.
    Both wizard steps, the level dropdown, the publish switch and every toast are Polish. Submitting with an empty title shows the Polish validation message, not "Title is required".
  6. Open the browser console on any page above.
    No hydration mismatch warnings — dates are formatted with an explicit locale on purpose.

B. Structural cleanup (regression sweep)

  1. Click through the main surfaces: dashboard, lessons, songs, users, assignments, theory, onboarding, settings.
    No blank screens or chunk-load errors. components/v2 and components/_ui no longer exist — every import was rewritten, so a missed one shows up as a runtime module error.
  2. Resize across the mobile/desktop breakpoint on lessons, songs and theory.
    Mobile shells and desktop layouts both render; the lazy desktop chunks still load.
  3. Run npm run check:structure.
    "Structure clean — no new findings."

C. Invite workflow

  1. As a teacher, open /dashboard/users and find a student who has never signed in but was already invited.
    The row shows a Resend invite → action (Polish: Wyślij ponownie →) — not a blank cell, and not the shadow-profile "Invite to claim" flow.
  2. Open that student's detail page.
    The same resend action appears in the header actions row.
  3. Trigger the resend.
    Shows Sending… → ✓ Sent. On failure the real Supabase error text is surfaced, not a bare "User not found".
  4. A shadow profile (never invited) still shows the invite-to-claim flow with the email input.
    Unchanged behaviour — the resend path must not overwrite invite_email on a non-shadow profile.
  5. Ops half: after any supabase stop/start on the dev stack, run python3 scripts/ops/restore-gotrue-mail-urls.py and follow docs/runbooks/supabase-stack-restart.md.
    Auth email links point at the configured site URL again instead of the container default — this is the failure that silently broke every invite link after a CLI restart.

D. Edge cases worth a look

  • A course whose level is some value other than beginner/intermediate/advanced — the chip should fall back to the raw string, not crash or show a missing-translation error.
  • A profile with no row in profiles: the proxy should log a warning and let them through, not trap them in a redirect loop.
  • A deactivated account: still bounced to sign-in with error=account_deactivated.
  • Locale precedence: DB preference beats the cookie, which beats Accept-Language, which beats the default.
