Calendar: lessons appear again, and the month fits a phone

2026-10-14 · branch fix/walkthrough-review-10-calendar-mobile

What changed

  • Bug fix: the calendar queried lessons by the auth id, but lessons are keyed by profile id since S2, so the grid was empty for every teacher and student. It now uses the profile id (Google integration lookup keeps the auth id, which is what that table stores).
  • Phone: all seven columns fit (no sideways scroll); each day shows coloured dots, and under the grid a list of this month's lessons grouped by day ("wt., 6 paź · 20:03 Zofia Nowak"). Desktop keeps the chips.
  • Event chip moved to its own module to keep the calendar under the 200-line limit.

How to test

  1. Dev stack with demo data. As the teacher open /dashboard/calendar at 390 px: dots on lesson days, today highlighted, the list underneath; tap a row to open the lesson.
  2. Same at 1440 px: chips with time and student, "+N więcej" on busy days.
  3. As the demo student: only their own lessons, labelled by lesson title.
  4. Go to a month with no lessons: "Brak lekcji w tym miesiącu." under the grid on a phone.
  5. Production check after merge: a real teacher account sees their lessons on the calendar.
