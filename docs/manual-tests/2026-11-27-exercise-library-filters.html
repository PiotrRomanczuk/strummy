Exercise library: filters, search, pages

Date: 2026-11-27 · Issue #1213 · Branch feature/exercise-library-filters

What was done

  • Library filtered in the query. /dashboard/exercises takes ?kind= (riff, chords, strum, other), ?song= (song id), ?q= (name contains) and ?page=. The address is validated with Zod (schemas/ExerciseListParamsSchema.ts); a wrong value is dropped instead of breaking the page.
  • Pages of 25 with range() and an exact count, so the list never loads the whole table and never hits the 1000-row cut. The header count shows all matches, the pager says "Page 2 of 11" and keeps the filter.
  • Exercises of deleted songs are now filtered in the database (songs!inner + songs.deleted_at is null), so they do not inflate the count.
  • Song page: staff see a card "Exercises from this song" in the sidebar, each exercise opening the song card on its part, plus a link to the library filtered to that song. Hidden when the song has none.
  • One tempo range, 40–100% (schemas/PracticeTempoSchema.ts) for a saved exercise, the card's ?tempo= link and a student's progress mark (was 1–200% for the mark). It is what the card can play: 0.4–1× speed, mastered at 100%.
  • Not in this PR: editing an exercise (name, kind, tempo, note) — follow-up PR. The student_song_progress check constraint in the database stays 1–200 (wider than the app allows, harmless); narrowing it is a separate migration.

How to test manually

Dev stack, signed in as the dev teacher (or admin). npm run dev, then:

  1. Open /dashboard/exercises. Expect the count of all exercises (≈261 on dev), the filter row, 25 rows and a pager at the bottom.
  2. Pick Kind = Riff, press Show. Address becomes ?kind=riff, every row is a riff, count drops.
  3. Also pick a Song. Only that song's riffs remain. "Clear filters" goes back to the full list.
  4. Type part of a name in Name (e.g. intro) and press Enter. Matches are case-insensitive; typing % finds names containing a percent sign, not everything.
  5. Press Next: &page=2 is added, the filter stays. Go to ?page=999: empty state "No exercise matches this filter". Go to ?kind=solo&page=abc: the page loads unfiltered on page 1.
  6. Open a song that has exercises (e.g. "About a Girl" on dev). In the right column: "Exercises from this song". Open on a row → the card on that part, looping, at the saved tempo. "In the library" → the library filtered to the song.
  7. Open the card with ?tempo=35 or ?tempo=120: plays at 100%. ?tempo=40: plays at 40%.
  8. Sign in as the student and open a song page: no exercises card (staff only, RLS).
  9. Phone width (375px): the filter fields stack, the pager fits on one line. Dark mode: tokens flip with the theme.
