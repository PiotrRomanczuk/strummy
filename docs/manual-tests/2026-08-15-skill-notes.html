SKL-3 — skill notes, and the bug that would have eaten them

2026-08-15 · branch feature/skill-notes · doc 11

The bug, found before the feature

student_skills.notes has existed for months: the column, the Zod field, and the action parameter. Nothing ever passed it and nothing rendered it. But the update branch wrote:

notes: notes ?? null

So the first status change from the dropdown — which passes no notes — would have erased whatever the teacher had written. Harmless while the column was dead; a feature broken on first use the moment notes got a UI. It is fixed in the same commit that adds the UI, and the payload now omits the column rather than nulling it:

...(notes !== undefined ? { notes: normalizeNote(notes) } : {})
Written test-first. Two tests failed against the old action (preserves an existing note, clears a note when an empty string is supplied) and passed after the fix.

One constraint, accepted rather than worked around

upsertStudentSkill takes status as a required argument, so a note cannot attach to an unassessed skill. Rather than widening the mutation surface, the note control only appears on a skill that already has a status. A note about nothing is not an assessment.

An accessibility fix the test forced

Writing the E2E surfaced that a level renders 20+ identical "Add note" buttons — indistinguishable to a screen-reader user. Every note control now carries its skill in the aria-label (Add note: Open chords (E, A, D, G, C)), mirroring what the status select already did. That is a real fix, not a test workaround — and it is what makes the test able to target one row without depending on DOM structure.

How to verify manually

  1. As teacher, open a student → Skills → any row that already has a status.
  2. Click Add note, type, Save. The note appears under the skill name.
  3. Now change only the status on that same row. The note must still be there — that is the bug this PR fixes.
  4. Edit the note to empty and save: it disappears (empty means remove).
  5. A row with no status offers no note control at all.
  6. As student, open My Skills: the note is visible as plain text, with no button and no textarea.
  7. In Polish: "Dodaj notatkę" / "Edytuj notatkę" / "Zapisz" / "Anuluj".
