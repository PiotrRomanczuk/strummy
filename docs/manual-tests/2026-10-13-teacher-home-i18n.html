Teacher home in the viewer's language

2026-10-13 · branch fix/walkthrough-review-4-home-i18n

What changed

The teacher dashboard (phone and desktop) had no translations: every label, date and time was hard-coded English, so a Polish teacher saw "Next · in 46m", "Week 42 · density", "Good morning" and "4:00p". All of it now comes from a new TeacherHome namespace in messages/en.json and messages/pl.json, with Polish plural forms ("1 lekcja / 3 lekcje / 12 lekcji").

  • Dates and weekday initials use the viewer's locale; Polish gets a 24-hour clock ("16:00") on the day spine, timeline and roster.
  • "Needs attention" reasons are data now and rendered in the viewer's language.
  • The skills page greeting ("Good morning, Anna") uses the same translated greeting.
  • The shared phone header date ("wtorek · 13 paź") is localized for both roles.
  • English output is unchanged: the existing dashboard tests pass without edits.

How to test

  1. Dev stack, npm run seed:demo -- --yes, then npm run dev.
  2. Sign in as the demo teacher (Anna Kowalska, profile locale pl) and open /dashboard at 390 px width. Expect: date eyebrow in Polish, "Dziś · 3 lekcje", times as 11:00, "Wymaga uwagi · 1" with "Zadanie po terminie: 2 dni", week tiles P W Ś C P S N.
  3. Same page at 1440 px. Expect "Dobry wieczór, Anna." (or the right time-of-day greeting), "Dzisiejszy plan", Dziś / Tydzień / Miesiąc, hour gutter 9:00…20:00, "Otwórz" / "Przygotuj →" on lesson blocks, "Ten tydzień a poprzedni".
  4. Open /dashboard/skills. Expect the greeting in Polish.
  5. Switch the language toggle to English. Expect the previous English dashboard, unchanged ("4:00p", "Good afternoon").
  6. Edge: a day with no lessons shows "Dziś bez lekcji." on the phone and "Nic nie zaplanowano" on desktop.
