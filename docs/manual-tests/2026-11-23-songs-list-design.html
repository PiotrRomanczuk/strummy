Date: 2026-11-23 · Branch: fix/songs-list-design · Reference: Claude Design project "Strummy", file src/song-list.jsx ("Strummy - Song List").

Songs list matches the Claude Design mockup

What was done

The teacher's songs list (/dashboard/songs) was compared with the mockup and brought in line with it. Nothing about the data or the URLs changed; this is layout only.

BeforeAfter
Category tabs glued to the filter box, with a grey scrollbar and a gap above the tableTabs sit directly on the table and are its top edge; they scroll sideways without a scrollbar; counts use the shared tab-count pill
Three stacked control rows: full-width search, chip row, a boxed key/author formFrom 768 px up one toolbar row (search 300 px, key, author, sort on the right) and the level chips below it
Rows 66 px tall54 px, as in the mockup
Level printed as plain textColour dot + label: green for starter/beginner, gold for intermediate, red for advanced
Key, learners, mastery and added date all left-alignedKey centred and medium weight; numbers and the date right-aligned, headers too
With the detail panel open the title column shrank to almost nothingThe table drops "Mastery" and "Added" while the panel is open (the panel shows them), so the title stays readable
Three header buttons of equal weightOne ink primary, two quieter ghost buttons

The shared DataList gained two opt-in props, attached and dense, and align="center". Lessons and Repertoire do not pass them and look as before.

Not done

  • Learner avatars in the "Learning" column: the list query returns only a count.
  • The mockup's 34 px upright page title with the count beside it: the 40 px italic title was left as is.
  • The mockup's tag filter: songs have no tags in the app.
  • A full-height table with a sticky header: the whole page still scrolls.
