Parent panel polish (#1092)

Date: 2026-11-27 · Branch: fix/parent-panel-polish-teacher-name · Scope: family dashboard (/dashboard as a parent)

What was done

  • Teacher's name, without the service role. The parent dashboard used to fill in the teacher's name with the admin (service-role) client, because RLS gives a parent the child's lessons but not the teacher's profile. It now calls a new SECURITY DEFINER function public.child_teacher_names(p_child_id) as the signed-in parent. It returns only id and full_name, only for teachers of non-deleted lessons of a child linked to the caller (is_child_of_parent); for anyone else it returns an empty list. No SELECT policy on profiles was added, so #1096 is not widened. The owner who teaches as an admin is now covered too (the old lookup filtered on is_teacher = true).
  • Remaining English in the panel. Practice-day labels were English weekday names produced on the server ("Tue"); they are now formatted in the viewer's language from the day key ("wt."). The " min" unit and the child switcher (now a <nav> with an accessible name "Twoje dzieci" / "Your children") go through next-intl. The child switcher's inline style became Tailwind classes, which also lets the active-tab colour from design-tokens.css apply.
  • Migration: supabase/migrations/20261127120000_child_teacher_names.sql (additive, idempotent create or replace, execute granted to authenticated only). database.types.ts gets the matching Functions.child_teacher_names entry; CI's types-drift job regenerates from the branch's migrations and verifies it.

How to test manually

  1. After the PR merges into dev, deploy-db.yml applies the migration to the dev stack. Then run npm run dev against it.
  2. Sign in as the dev parent account (a parent linked to a student who has lessons with a teacher).
  3. Open /dashboard with the Polish locale. Expected:
    • the hero subtitle reads "… · nauczyciel: <imię i nazwisko>";
    • each upcoming lesson row ends with " · <nauczyciel>";
    • the note card title reads "Ostatnia notatka od: <imię>";
    • no English text anywhere on the page (with practice enabled: weekday labels like "pon.", "wt.", and "Dziś"/"Wczoraj").
  4. With two linked children, the switcher shows both; the active one is highlighted.
  5. API check (as the parent, with the parent's access token): 
    POST /rest/v1/rpc/child_teacher_names  {"p_child_id": "<own child id>"}
→ [{"id": "...", "full_name": "..."}]          (only these two keys)
POST /rest/v1/rpc/child_teacher_names  {"p_child_id": "<someone else's student id>"}
→ []
GET  /rest/v1/profiles?id=eq.<teacher id>&select=*
→ []                                             (profile row still hidden)
  6. Edge cases: a lesson that was soft-deleted does not reveal its teacher; a child with no lessons shows no teacher and no "nauczyciel:" fragment.
