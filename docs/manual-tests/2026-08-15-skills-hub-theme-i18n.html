What was wrong

  • Un-themed. The last /dashboard page still rendering raw shadcn on the default canvas — 20 sibling pages wrap in theme-strummy, including /dashboard/fretboard, one nav slot away.
  • Hardcoded English. "Skills", "Chord Quiz", "{n} due" shipped untranslated. Structure check C22 only scans components/, never app/, so a whole page of English strings passed CI.
  • Missing PL key. Skills.diagramAriaLabelHidden existed in en.json only. In next-intl a missing key throws at render.

Why the extraction. Inlining the tile pushed the page function to 83 lines against an 80-line lint ceiling — a new warning, which rule S9 forbids (warning counts ratchet, they never grow). The tile is also the natural seam: a second practice tool is expected here.

A defect found while verifying

.theme-strummy paints background: var(--ivory) on itself, so it covers only its own box. This page is one card tall, which left the canvas half ivory, half the layout's default — obvious on a wide screen. Fixed with minHeight: 100% on the wrapper. Taller themed pages hide the same seam behind content; worth knowing before the next short page.
