Starter — a fourth song difficulty below Beginner

Date: 2026-08-06  ·  Branch: feature/songs-starter-difficulty-level  ·  Scope: songs only — theory courses unchanged

⚠ Deploy order matters — read first

The migration has been applied to StudentDevelopment only. Production does not yet have the starter enum value. Two consequences:

  • The db-parity CI job compares the two schemas and will fail until production is migrated. That failure is expected, not a defect in this branch.
  • If this merges before production is migrated, the form would offer a Starter button that Postgres rejects on save — a user-facing error.

Apply to production before merging:

cat supabase/migrations/20260806120000_songs_starter_difficulty_level.sql \
  | ssh uwh "docker exec -i supabase_db_StudentProduction psql -U postgres -d postgres -v ON_ERROR_STOP=1"

The statement is additive and idempotent — it adds a label and changes no rows. It is, however, irreversible: Postgres cannot drop an enum value without recreating the type and rewriting the column.

What was built

Songs gain a fourth difficulty, Starter (PL: Początkowy), ordered below Beginner. It is for first-weeks material — one- and two-chord songs, no barre, slow strums — which previously had to share the Beginner bucket with genuinely beginner-level repertoire, making that level useless as a filter at the shallow end.

Nothing changes for existing songs. No row was migrated, and new songs still default to Beginner; Starter is opt-in.

Theory courses are untouched. They use a separate Postgres enum (theoretical_course_level) and keep their three levels.

Ordering

The migration places the value BEFORE 'beginner', so the enum's own sort order stays lowest-to-highest and ORDER BY level keeps working with no CASE expression: 

starter < beginner < intermediate < advanced

Worth a second opinion: the Polish label

Początkowy (Starter) and Początkujący (Beginner) share a stem and look very similar side by side in the picker — the same near-synonym problem that argued against calling the English level "Basic", reappearing in translation. If it reads ambiguously in use, Pierwsze kroki ("first steps") is a one-line change to messages/pl.json; the enum value itself would not move.
