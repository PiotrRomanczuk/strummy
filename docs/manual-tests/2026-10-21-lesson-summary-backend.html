Podsumowanie po lekcji — backend (generowanie, zapis, mail)

Data: 2026-10-21 · Gałąź: feature/lesson-summary

Co zostało zrobione

  • Migracja 20261021150000_lesson_summary.sql: lessons.summary, summary_generated_at, summary_sent_at (tylko dodanie kolumn; uczeń czyta lekcję jak dotąd).
  • Prompt v2 po polsku (lib/ai/agents/post-lesson-summary-prompt.ts): wiadomość do ucznia na „ty”, 60–120 słów, tylko fakty, praca domowa tylko gdy jest, daty słownie. Benchmark na 4 lekcjach: stary prompt 0/4 poprawnych na każdym modelu (angielski, 2–4× za długi, zmyślone BPM i minuty, wymyślona praca domowa); v2 4/4 na gemma4:12b i nemotron-3.5.
  • Serwis lib/services/lesson-summary.ts: sam zbiera dane lekcji z bazy (piosenki ze statusami i notatkami, notatki lekcji, praca domowa przypisana do lekcji, data następnej lekcji), generuje (LESSON_SUMMARY_MODEL → LESSON_DRAFT_MODEL → nemotron), zapisuje przy lekcji, loguje do ai_generations; wysyłka jako powiadomienie lesson_recap (mail + w aplikacji, język polski wymuszony).
  • API GET/POST /api/lessons/<id>/summary — body { text?, regenerate?, send? }; klucz API albo sesja; tylko nauczyciel lekcji lub admin.
  • Mail: szablon lesson recap pokazuje wiadomość nauczyciela zamiast ogólnego powitania, przycisk prowadzi do lekcji, polski temat „Podsumowanie lekcji z …”.
  • Bramka maili do uczniów (lib/services/student-email-gate.ts, jedna definicja zamiast dwóch kopii): poza STUDENT_EMAILS_ENABLED=true nowa zmienna STUDENT_EMAIL_TYPES=lesson_recap wpuszcza tylko wybrane typy — podsumowania można wysyłać bez włączania przypomnień i podsumowań tygodniowych.

Jak przetestować ręcznie

  1. Po wdrożeniu (migracja wejdzie automatem Deploy DB) ustawić na Vercelu STUDENT_EMAIL_TYPES=lesson_recap i zrobić redeploy — bez tego uczeń dostaje tylko powiadomienie w aplikacji.
  2. Wygenerować bez wysyłki (lekcja z piosenkami): 
    curl -sS -X POST "https://strummy.online/api/lessons/<lessonId>/summary" \
  -H @"$HOME/.config/strummy/curl-auth-header" -H 'Content-Type: application/json' \
  --data '{}' -w '\nHTTP %{http_code}\n'
    Oczekiwane: 200, summary po polsku, zaczyna się „Cześć <imię>,”, kończy „Piotr”, bez BPM/minut, praca domowa tylko gdy była przy lekcji.
  3. Poprawić tekst: --data '{"text":"Cześć ... Piotr"}' → zapisany tekst wraca bez generowania.
  4. Wysłać: --data '{"send":true}' → sent: true; mail „Podsumowanie lekcji z 20 października” u ucznia (test: Quentin ma adres-alias właściciela), powiadomienie w aplikacji prowadzi do lekcji, summary_sent_at ustawione.
  5. Przypadki brzegowe: lekcja bez piosenek i notatek → 409 empty; cudza lekcja → 404; {"regenerate":true} nadpisuje zapisany tekst.
