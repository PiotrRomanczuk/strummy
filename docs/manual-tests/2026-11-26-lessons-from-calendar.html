Lessons follow Google Calendar

What changed

  • Which events are lessons (isGuitarLesson): Calendly bookings, where every recurring guitar lesson lives, except those whose title starts with Ang, Angielski or English (English lessons booked through the same Calendly page). Cal.com bookings stay out: the Cal.com webhook already makes their lessons, so reading their calendar copy would double them. Hand-typed events stay out.
  • A moved event moves its lesson. When an imported lesson is still SCHEDULED and its event has a new start or length, the lesson follows. A lesson the teacher already ran, completed or cancelled is never touched.
  • A deleted or cancelled event cancels its lesson. The sync now asks Google for deleted events too (showDeleted) and sets the teacher's SCHEDULED lessons with those event ids to CANCELLED. Calendly cancels the old event when a student reschedules, so a reschedule is a cancel plus a new import.
  • The webhook sync actually runs. It used to start an un-awaited promise after replying to Google, which a serverless function may freeze. It now uses after() with maxDuration = 60.
  • No migration, no new environment variable.
