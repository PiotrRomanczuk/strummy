How to test on dev

  1. npm run dev against StrummyDevelopment; sign in as the dev teacher.
  2. Open a song that has an analysis (song page → "Karta utworu"). At the bottom: "Postęp ucznia" asks for a student.
  3. Pick a student. The address gets ?student=…; status "nie zaczęty", every row "jeszcze nie zaznaczono".
  4. Tap 75% on the verse row: the row shows "75% · 27 lis", the 75% button is highlighted, status "zaczęty".
  5. Tap 100% on every row: status "opanowany". Reload: the same state comes back from the database.
  6. Tap 60% on one row: status goes back to "zaczęty" (latest mark wins; history keeps all rows).
  7. Open a song without an analysis: the card says there is no analysis, and the panel shows one row "Cały utwór".
  8. Add &lesson=<id of a lesson of that student>, tap a tempo, and check student_song_progress.lesson_id on dev.
  9. Sign in as the student and open the same card: the panel is not shown.
  10. Tablet width (768 px) and phone width: the buttons wrap, nothing scrolls sideways; dark mode uses the card tokens.
