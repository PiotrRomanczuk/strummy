Strummy — Student & Teacher POV Deep Analysis

Date: 2026-08-01  ·  Method: live Playwright (MCP) walkthrough of https://strummy.online (production)  ·  Accounts: p.romanczuk+testteacher@gmail.com (Teacher), p.romanczuk+teststudent@gmail.com (Student)  ·  Scope: every dashboard surface for both roles; writes limited to test entities (all cleaned up)
Headline: The read/browse experience is polished and works for both roles — but the teacher's core creation loop is completely broken in production. The Student dropdown is empty in the lesson form, the assignment form, and both AI tools, so a teacher cannot schedule a lesson, set homework, or run AI insights for anyone. AI Chat is also fully down (every message returns the error fallback). The student side, including the new pick-a-song repertoire flow, works end to end.

Root cause note (F1–F3): three independent surfaces show the same symptom — the teacher's student list is empty wherever it feeds a creation/tool context, while the Students page and dashboard roster (a different query path) are fine. This matches the id-space regression being fixed on the current branch fix/identity-id-space-regression ("stop passing auth ids where profile ids are required", commit 72515370): the teacher-students lookup is keyed by the auth user id where a profile id is required, so the join returns nothing. The fix exists locally but is not merged/deployed — shipping that branch should resolve F1, F2 and F3 at once. The student-side pick-a-song write (same regression family) already works in production, consistent with the teacher-side lookup being the remaining broken half.

2 · Teacher POV

Works correctly

  • Sign-in / session — email+password, Google SSO button, demo-account entry, forgot-password link.
  • Dashboard — greeting with date, today's schedule strip, week-density chart, studio-utilization stat, quick shortcuts, student roster, "Song of the week" with assign link, activity feed empty state.
  • People list — all 4 students with role badges, join dates, search, role/active/student-status filters, "Resend invite" for unclaimed accounts.
  • Student profile — header stats (in-progress/mastered), level/genre tags, Message / Schedule lesson / Import songs actions, Overview–Lessons–Repertoire tabs, recent-lessons feed, teacher-notes panel.
  • Lessons list — 31 lessons grouped by date with status counters (Scheduled/In-progress/Completed/Cancelled), year filter, sort toggle.
  • Lesson detail — per-song mastery stage pills, notes panel, details sidebar, homework section, Continuity (previous lessons with the same student).
  • Lesson edit view — loads with populated data (status, schedule, duration, format, repertoire picker) — just unlinked (F8).
  • Songs library — 396 songs, level filter with counts, key/author/title filters, 3 sort orders, pagination (8 pages).
  • Song detail — hero with cover/key/tempo/time/length, chord voicing diagrams, lyrics with inline chords, UG/YouTube/Spotify resources, usage stats, related songs, Production tab, Edit link.
  • Add-student form — 4 sections (identity, contact incl. parent, recurring schedule, billing) with live preview card (not submitted — production).
  • Skills / Chord Quiz, Calendar grid, Fretboard, Notifications, Settings — all render and function; API-key management and Google Calendar connect surface present.

Broken / degraded

  • Cannot schedule a lesson — empty student dropdown + ignored ?studentId= (F1). This kills the app's core loop.
  • Cannot create an assignment — same dropdown bug (F2); assignment templates & chord-drill builder are all dressed up with nowhere to go.
  • AI Progress Insights & Email Generator unusable — empty student picker (F3); "Analyze Progress" / "Generate Email Draft" stay disabled.
  • AI Chat dead — every message returns the model-unavailable fallback (F4), plus hydration error #418 (F5).
  • Lesson numbering wrong for imported history (F6); past lessons stuck "Scheduled" (F7).
  • Test data visible: E2E lessons/songs, control songs, junk titles at the top of "Newest first" (F9, F10).
  • Cosmetics: mangled greeting fallback, Teacher "—" on imported lessons (F14).

3 · Student POV

Works correctly

  • Sign-in with email/password lands on a role-correct dashboard (Student nav: My Lessons / My Assignments / My Repertoire / Song Library / Fretboard / Skills).
  • Dashboard — next-lesson and repertoire cards with sensible empty states.
  • My Lessons — correctly scoped to the student's own 2 lessons only; status/year filters work.
  • My Assignments — status tab bar, search, sort, friendly empty state ("No assignments on your desk. Enjoy the quiet.").
  • Pick-a-song flow (new) — "Want to learn" in the Song Library flips to "Remove", the song appears in My Repertoire at stage "To learn", and removal works. Verified end to end with a real write.
  • Repertoire notes — per-song "My notes" panel with note text + difficulty 1–5 saves correctly (badge flips to "Note").
  • Student song detail — practice progress bar (5 stages), resources, remove-from-repertoire.
  • Chord Quiz — 10-question flow with immediate Correct/Next feedback.
  • Access control — teacher routes (/dashboard/users) redirect the student back to /dashboard; no teacher nav is offered.
  • Settings — profile page with email/role locked, display name editable.

Broken / degraded

  • Stale copy contradicts the new feature — repertoire & dashboard empty states still claim only the teacher can add songs (F11).
  • Teacher-only copy leaks to students — "Edit the song to add chords" (F12).
  • Quiz alt text reveals the answer (F13).
  • Past lessons shown as "Scheduled" in My Lessons (F7) — confusing for a student looking at April lessons in August.
  • Content gaps surface to students — e.g. Thunder has no chord chart or lyrics; most catalog entries lack level/key (F10), so the library reads half-finished from the student side.
  • (Blocked upstream) A student can't receive lessons or homework right now because the teacher-side creation is broken (F1/F2) — the student's core loop starves even though their UI works.
