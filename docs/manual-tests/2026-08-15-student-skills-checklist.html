SKL-1 — the student can finally see their own skills

2026-08-15 · branch feature/student-skills-checklist · route /dashboard/my-skills · doc 11

What was wrong

The teacher has been assessing students against a 79-entry curriculum checklist for weeks. The student could not see any of it. RLS already granted Students can view their own skills, and the read-only UI already existed — the only way in was typing /dashboard/users/<your own id>, which no student would guess.

This is the left half of a feedback loop that had no right half. Nothing new was built to fix it: the query, the permission and the read-only rendering all existed. What was missing was a door.

The empty-state decision

A student shown the full catalog would open on ~79 rows reading "not started" and every progress bar at 0% — technically honest, but it reads as "you have learned nothing". So the student view shows only assessed skills (assessedOnly).

The subtlety that makes it work: lesson progress still counts against the whole lesson. In the screenshot, Lesson 999 reads "1/2 mastered" with a single row visible — the student can see there is more in that lesson without being shown a skill nobody has assessed. Filtering the denominator too would have read "1/1" and quietly claimed the lesson was finished.

Evidence

A defect found while verifying

Clicking Intermediate as a student rendered a completely blank panel. The catalog has 32 skills there, so the "no skills catalogued" branch did not fire; the level rendered its lessons and the assessed-only filter then removed all of them. Worse than a wrong message — no message at all. Now a distinct state: "Nothing assessed at this level yet — your teacher will get here." The existing string was a statement about the catalog and would have been false to show a student.

How to verify manually

  1. npm run dev, sign in as the student account.
  2. Sidebar → Learning → My Skills (one click from the dashboard).
  3. Only skills your teacher has assessed appear. Header reads "Your progress" / "The skills your teacher is tracking with you."
  4. There is no dropdown anywhere — statuses render as plain badges.
  5. Open a lesson that is partly assessed: the count denominator is the full lesson, not the visible rows.
  6. Click a level you have not started — you get the "nothing assessed" line, not a blank box.
  7. Sign in as teacher → open any student → Skills tab: unchanged, full catalog, dropdown on every row.
  8. As teacher or admin, visit /dashboard/my-skills directly → redirected to the roster.
  9. Switch to Polish: "Moje umiejętności", "Twoje postępy". No missing-key crash.
