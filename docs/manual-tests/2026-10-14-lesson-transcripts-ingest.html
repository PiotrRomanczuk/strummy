Lesson transcripts — ingest API + read-only card on the lesson page

Date: 2026-10-14 · Branch: feature/lesson-transcripts · Gap: CNT-5 (docs/app-blueprint/09-content-production.md) · Migration: 20261014150000_lesson_transcripts.sql

1. What was done

  • New table lesson_transcripts — one transcript per lesson (lesson_id unique), source enum (wispr / paste / upload), the recorder's external_id (unique), recorded_at / ended_at, summary (≤ 20 000 chars), body (≤ 100 000 chars), language, share_link, created_by. RLS: only the lesson's teacher or an admin can read or write it — a student always gets 0 rows.
  • POST /api/transcripts/ingest — an external recorder (Wispr Flow through a scripted client) sends the transcript with the student's email and the recording's start time. Strummy finds the student (by email or invite_email, case-insensitive, never creates one), picks that student's lesson closest to the start time (±90 min) or creates a COMPLETED lesson for the teacher who is calling, and stores the transcript. Sending the same external_id again updates the text instead of duplicating it.
  • "Transkrypcja" card on /dashboard/lessons/<id> (desktop left column under the notes; phone under the notes section) — collapsed by default, shows recording time, source, summary, the full text in a scrollable block, and a link to the recording when one was sent. Rendered only for the lesson's teacher / admin and only when a transcript exists. Polish and English strings.

3. Steps

3.1 Ingest — no lesson in the window → lesson created (201)

Pick a started_at at which the student has no lesson (e.g. a Sunday 06:00 next month). 

curl -s -X POST http://localhost:3000/api/transcripts/ingest \
  -H "Authorization: Bearer gcrm_XXXXXXXXXXXXXXXXXXXXXXXX" \
  -H "Content-Type: application/json" \
  -d '{
    "source": "wispr",
    "external_id": "wispr-rec-0001",
    "started_at": "2026-11-01T06:00:00+01:00",
    "ended_at":   "2026-11-01T06:45:00+01:00",
    "student_email": "STUDENT_EMAIL",
    "title": "Queen night",
    "summary": "Worked on Hammer to Fall; student loved Now I'\''m Here.",
    "transcript": "Teacher: Dzisiaj Hammer to Fall.\nStudent: Sztos, trzeba to nagrać!\nTeacher: Zapisuję.",
    "language": "pl",
    "share_link": "https://notes.wisprflow.ai/shared/example"
  }'

Expected: HTTP 201 and

{"lessonId":"<uuid>","transcriptId":"<uuid>","lessonCreated":true,"student":{"id":"<uuid>","name":"<student name>"}}

In Lessons a new lesson "Queen night", status Completed, 45 min, at the given time, with the calling teacher.

3.2 Re-send the same recording → update, same ids (200)

Repeat the curl with the same external_id and a changed summary.

Expected: HTTP 200, identical lessonId / transcriptId, "lessonCreated":false; the card shows the new summary; no second lesson.

3.3 Ingest onto an existing lesson (200)

Use a started_at within 90 minutes of a lesson that student already has, and a new external_id (e.g. wispr-rec-0002).

Expected: HTTP 200, lessonId = that lesson, lessonCreated:false. If that lesson already had a transcript, it is replaced (one transcript per lesson).

3.4 Error cases

Change Expected
Drop the Authorization header 401 {"error":"Unauthorized"}
Use a Student account's API key / cookie 403 {"error":"Forbidden"}
"student_email": "nobody@example.com" 404 {"error":"No student matches student_email","code":"student_not_found"} — no profile is created
"transcript": "short" or "started_at": "yesterday" 400 {"error":"Invalid transcript payload","issues":[…]}
Body {not json 400 {"error":"Invalid JSON body"}

3.5 The card on the lesson page

  1. Signed in as the Teacher, open /dashboard/lessons/<lessonId> from step 3.1.
  2. Desktop (≥ 768 px): below Lesson notes there is a collapsed card NAGRANIE / Transkrypcja (EN: RECORDING / Transcript) with a chevron. Click it.
  3. Expected when open: "Nagrano <date · time in the viewer's locale>", "Źródło Wispr Flow", link "Otwórz nagranie" (opens the share link in a new tab), Podsumowanie paragraph, Pełna transkrypcja block that preserves line breaks and scrolls when long (max 420 px).
  4. Phone (< 768 px): the same card sits between Notes and Assignments.
  5. Switch the language (PL ↔ EN) — labels follow the locale, the date format too.
  6. Sign in as the Student of that lesson and open the same URL — no transcript card. Verify at the DB level too: npm run test:rls → suite lesson_transcripts RLS (6 tests) proves the student gets 0 rows and cannot insert.
  7. A lesson without a transcript shows no card at all (not an empty one).
