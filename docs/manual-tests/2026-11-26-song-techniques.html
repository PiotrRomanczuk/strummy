Song techniques (#1206, part of #1146) — manual test

No browser run was possible. The table song_techniques is not on the dev database yet (the migration lands there when this PR merges into dev), so the card and the filter were checked only by unit and component tests. The RLS test was written but not run for the same reason.

What was built

  • Table song_techniques (additive migration 20261126140000): per song the total note count and a count per technique. Any signed-in user can read the labels of a song they can read (the policy looks the song up under the songs policies, so it is never wider than songs); only teachers and admins write; anon has no access.
  • Rule (lib/music-theory/song-techniques.ts): a song has a technique with at least 8 marks and 1% of its notes, or at least 25 marks. Strength from the share of notes: under 3% a little, 3-10% regular, 10% and more a lot. Left out of chips and filter: stroke_down, stroke_up and the minor techniques ghost, grace, staccato, whammy, trill, tremolo_picking.
  • Loader scripts/backfill/2026-11-song-techniques.ts --file <jsonl> (--validateOnly | --commit) [--remote]: validates each line, skips unknown and deleted songs, upserts on song_id, prints a JSON summary.
  • Song page: card "Techniki w utworze" / "Techniques in the song" with a chip per technique and its strength, for staff and students; nothing when the song has no row.
  • Songs list: "Technique" select next to the key select; the URL carries ?technique=slide; the level and genre counts follow it.

How to test by hand (after the migration is on dev and labels are loaded)

  1. Run the loader with --validateOnly against dev; check the summary (loaded / skipped counts, problems).
  2. Run with --commit. Open a song that has labels as a teacher and as a student: the card shows chips ordered by density, with the explanation line.
  3. Open a song without labels: no card at all.
  4. Open /dashboard/songs, pick a technique: the list narrows to songs with that technique; "Any technique" restores it; other filters (level, key, author, search) still combine with it; reload keeps the choice.
  5. Switch the language to Polish: names read Hammer-on i pull-off, Slide, Podciągnięcia, Vibrato, Wybrzmiewanie (arpeggio), Nuty tłumione, Palm mute, Flażolety, Tapping, Triole.
