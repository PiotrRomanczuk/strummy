Nauczyciel zaprasza rodzica ze strony ucznia

2026-11-16 · gałąź feature/parent-invite · issue #1091 · bez migracji

Co zostało zrobione

  • Karta „Rodzic lub opiekun” na stronie ucznia (nauczyciel i admin): gdy rodzic nie jest podpięty — formularz z imieniem i e-mailem (wypełniony danymi rodzica z formularza ucznia) i „Zaproś rodzica”; gdy jest — imię, e-mail, stan („Bez zaproszenia” / „Zaproszony” / „Korzysta ze Strummy”), „Wyślij zaproszenie ponownie” i „Odepnij”.
  • Zaproszenie: istniejący rodzic z tym adresem jest użyty ponownie, inaczej powstaje profil rodzica, który zaproszenie przejmuje tak jak profil ucznia. Adres ucznia, innego ucznia lub nauczyciela jest odrzucany. Gdy samo wysłanie maila się nie uda, rodzic zostaje podpięty, a karta mówi, co poszło nie tak.
  • Naprawiony błąd po drodze: zaproszony rodzic po ustawieniu hasła trafiał do onboardingu z wyborem „nauczyciel czy uczeń” — mógł się w ten sposób zrobić nauczycielem albo utknąć. Teraz rodzic trafia prosto na panel rodzinny.
  • Komunikaty po polsku i angielsku; błędy, które nauczyciel może poprawić (adres ucznia, adres zajęty), mają własne zdania.

Jak sprawdzić ręcznie

  1. Jako nauczyciel na dev otworzyć ucznia bez rodzica, w karcie „Rodzic lub opiekun” wpisać imię i coś@dev.local, „Zaproś rodzica”.
  2. Mailpit dev (port API dev + 3): mail z zaproszeniem; link → ustawić hasło → panel rodzinny z dzieckiem.
  3. Spróbować zaprosić adres samego ucznia albo nauczyciela: komunikat o błędzie, nic się nie zmienia.
  4. „Odepnij”: karta wraca do formularza, rodzic przestaje widzieć dziecko.
