Admin: teacher leads list

2026-11-27 · issue #1214 · branch feature/admin-teacher-leads

What was done

  • New page /dashboard/admin/teacher-leads lists submissions from the public /for-teachers form, newest first: date, name, e-mail (mailto link), language, source, status. 25 per page, paginated in the database query (.range() + exact count).
  • Filter pills All / Unhandled (?filter=unhandled, status new). Changing the filter returns to page 1.
  • Each row has Mark replied (sets status contacted) and, once handled, Undo (back to new). Server action setTeacherLeadReplied, Zod-validated (id uuid, isReplied boolean), admin-checked, runs on the user's session so RLS applies.
  • Sidebar entry "Teacher Leads" / "Zgłoszenia nauczycieli" in the Students group, admin only. The page itself redirects non-admins to /dashboard on the server.
  • No migration. The table already has status (new | contacted | converted | declined) and an admin-only UPDATE policy; "replied" = any status past new. The reply time is updated_at.
  • All strings in messages/en.json and messages/pl.json (TeacherLeads.*, Nav.teacher-leads).

How to test manually

  1. npm run dev against StrummyDevelopment; sign in as the dev admin role account (defaults in playwright.config.ts).
  2. Sidebar → Students → Teacher Leads. Expected: table, newest at the top, subtitle "N submissions from the For teachers form".
  3. Fill in /for-teachers in a private window with an invented name and an @example.com address. Reload the admin page: the lead is first, status New, language from the browser locale.
  4. Click Unhandled: URL gets ?filter=unhandled, only New rows remain.
  5. Click Mark replied on your lead: toast "Marked as replied", the row leaves the Unhandled view; in All it shows Replied and an Undo button. Undo puts it back.
  6. With more than 25 leads, Next goes to ?page=2; on the Unhandled filter it keeps filter=unhandled.
  7. Switch the language to Polish: all labels and the plural subtitle are Polish.
  8. Sign in as the teacher and the student: no sidebar entry; opening /dashboard/admin/teacher-leads directly redirects to /dashboard.
  9. Clean up: delete your test lead (and its auth_rate_limits row) from the dev stack.
