No browser run was possible. The song_exercises table is not on the dev database (the migration reaches it only after the PR merges into dev), so nothing here was clicked through in a real browser and there are no screenshots. What was run: typecheck, lint, the whole Jest suite and component tests with a mocked Supabase. The RLS test was written but not run.

What was built

  • Migration 20261126120000_song_exercises.sql: new table song_exercises (song, recording, part number, name, kind riff/chords/strum/other, tempo 40–100%, source recording/backing, note), unique per song + part + name. RLS: only admin/teacher can read, add, change and delete; students and anonymous get nothing. Additive only (migrate-db.sh classify says additive).
  • Song card: a staff-only button Save as exercise next to Practice link. It is off until a part is selected. The dialog has a name (prefilled "part name – song title"), a kind and an optional note; tempo and source are whatever the card is set to.
  • Library /dashboard/exercises (staff only; a student gets a 404): name, kind, song and author, part, tempo, note, a link that opens the card on that part in a loop at that tempo, a delete control (two clicks), and an empty state explaining how to add the first exercise. "Exercises" is in the teacher menu after Songs.
  • All text in English and Polish.

How to test by hand (after the migration is on dev)

  1. Sign in as a teacher. Open a song that has a card (/dashboard/songs/<id>/card).
  2. Choose a part, switch to the backing track, set the tempo to 60%. Press Save as exercise. Check: the name reads "<part> – <song title>", the text under the title says the part and 60%.
  3. Pick Strumming, type a note, press Save. Check: "Saved. Find it under Exercises."
  4. Open the dialog again and save with the same name. Check: it says the part already has an exercise with that name. Change the name: the message goes away.
  5. Open Exercises in the menu. Check: the new row with kind, song and author, "Part n · 60% · backing track", the note.
  6. Press Open in the card. Check: the card opens on that part, looping, at 60%, on the backing track.
  7. Press Delete, then Sure?. Check: the row disappears. With nothing left the empty state shows.
  8. Sign in as a student and open /dashboard/exercises. Check: page not found. The card shows no Save as exercise button.
  9. Switch the app to Polish and repeat steps 2–5 once: "Zapisz jako ćwiczenie", "Ćwiczenia", kinds Riff / Zmiana akordów / Bicie / Inne. Look at the dark theme too.

Not covered in this slice
