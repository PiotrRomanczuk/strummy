Demo guided tour (driver.js)

Date: 2026-07-28 · Branch: feature/demo-tour

What was built

Demo accounts now get a first-run guided walkthrough of the app (driver.js, MIT, ~5 KB gz). A recruiter landing in the demo sees a 4–6 step tour of the core surfaces instead of a blank stare. Real accounts never render the component or download the library — the dashboard layout mounts it only for profiles with the is_development flag (the same gate as the demo banner and mutation guards), and driver.js is dynamically imported inside the component.

Piece Detail
components/demo/DemoTour.tsx Client island: auto-starts once per role (localStorage strummy-demo-tour-v1-<role>), floating "?" button replays it. Steps whose anchor is off-screen (mobile) are filtered; tour skips itself below 2 visible steps.
components/demo/demoTour.steps.ts Teacher tour (6 steps: overview → Lessons → Songs → Assignments → Students → AI) and student tour (4 steps). Anchors reuse the existing data-nav-item attributes — zero nav markup changes.
app/globals.css Popover themed via existing CSS variables — dark mode flips for free.
jest.config.ts CSS imports mapped to an empty module (house mock pattern), needed for driver.js/dist/driver.css.

How to manually test

  1. Sign in at strummy.vercel.app as sarah@strummy.app / Demo2024! (after this PR deploys).
  2. The tour should auto-open on the dashboard within ~1s: "Welcome to Strummy", 6 steps, Next/Back/Done, progress indicator.
  3. Press Esc or finish — reload the page: the tour must NOT reopen.
  4. Click the floating ? button (bottom-right): the tour replays.
  5. Repeat as emma@strummy.app — the student variant (4 steps) shows instead.
  6. Sign in as a real (non-demo) account: no tour, no ? button, and the driver.js chunk is absent from the network tab.
  7. Toggle dark mode and replay: popover follows the theme.
