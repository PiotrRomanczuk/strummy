ASG-6 — admin sees every teacher's assignments

Date: 2026-11-13 · Stack: StrummyDevelopment only · Migration: none

What was built

/dashboard/assignments filtered every non-student caller by teacher_id = <own profile>. An admin therefore saw only the assignments they had set themselves, although the RLS policy assignments_select_participant lets an admin read all of them. The owner is the only teacher and the only admin, so nothing looked wrong.

getAssignmentsList now takes a scope (student / teacher / admin) instead of a boolean. The admin scope adds no owner filter; the page picks admin whenever the account has is_admin, also when it is a teacher too. Teachers and students are scoped exactly as before.

Not verified in a browser

This change was made by the unattended dev agent, which may not touch a database or start the app. Only the unit tests ran (lib/services/__tests__/assignments-queries.test.ts, 11 tests). The steps below have not been performed by anyone.

How to verify by hand

Needs two staff accounts on dev that have each set at least one assignment — the Teacher role account and the Admin role account from CLAUDE.local.md are enough.

# Step Expected
1 Sign in as the Teacher. Create an assignment "ASG-6 teacher check" for any student. Note the count on the Open tab. The assignment is listed.
2 Sign out, sign in as the Admin, open /dashboard/assignments. "ASG-6 teacher check" is listed, although the Admin did not set it. Before this change it was missing.
3 As the Admin, switch the tabs (Open, Completed, Cancelled) and use the title search. Tab counts and rows include assignments from both teachers and agree with each other.
4 As the Admin, open /dashboard/assignments?student=<the student's profile id>. Only that student's assignments, from any teacher.
5 Sign in as the Teacher again. Only the Teacher's own assignments — none set by the Admin.
6 Sign in as the Student. Only the Student's own assignments, as before.
7 Delete "ASG-6 teacher check". Dev is left as it was.

Known limits

  • The list has no teacher column, so an admin cannot tell from a row who set the assignment.
  • The list still loads at most 500 rows and computes counts in the app. The admin scope spans every teacher and will reach that cap first.
