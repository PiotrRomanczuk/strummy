Data quality inside the repertoire statistics (SNG-13/14) — manual test

Date: 2026-11-16 · Branch: feature/repertoire-quality (stacked on #1107) · Tested on: the local Supabase stack on the Mac (StrummyLocal), admin account, Polish locale.

What was done

The two admin pages about songs became one. Data quality looked only at what was typed into Strummy; the repertoire statistics compared it with the recordings. Now:

  • The quality score knows the recording. Four consistency rules — song.key-recording, song.tempo-recording, song.chords-recording, song.duration-recording — fail when a field disagrees with the recording and nothing explains it (tuning, capo, relative key, half/double tempo, unsure analysis pass). A placeholder key (“C” without chords) or an impossible tempo stays a completeness problem, not a disagreement. The song page's quality card scores the same rules.
  • A “Data quality” view in the repertoire statistics: average score and bands, the fix queue (weight × failing songs, ?rule=), the songs to fix (most students first, then lowest score).
  • Fill from the recording (SNG-14). Where the tempo, key or chord list is empty and the recording knows it, a button proposes the value; nothing is written before “Save”. The server action recomputes the value, writes only an empty field, is admin only, respells keys to Strummy's sharps (Eb → D#), skips an unsure key and the key/chords of a song with a capo.
  • Overview shows the quality card beside coverage and disagreements.
  • /dashboard/admin/data-quality redirects to the new view (?rule= kept); the menu item and the old report components are gone. The rule engine in lib/data-quality/ stays for lessons and students (ADM-9).

How to test

  1. Sign in as admin, open Analytics → Repertoire Stats → Data quality.
  2. Click “Key disagrees with the recording” in the fix queue: the list narrows; “Show all” clears it.
  3. Click “Fill from the recording”, then “Enter tempo …” on a song: a confirmation appears; “Cancel” leaves the song untouched, “Save” writes it and the button disappears after the refresh. (Tested on the local “Demo Test Song”: tempo 130 saved, then restored by hand.)
  4. Open /dashboard/admin/data-quality?rule=song.key: you land on the new view with the filter.
  5. Open a song page: the admin quality card lists the recording rules too and links to the new view.
