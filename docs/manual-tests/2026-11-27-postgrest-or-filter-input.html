Search input in PostgREST or() filters (#1098)

Date: 2026-11-27 · Scope: backend only, no UI change, no migration

What changed

  • One helper, cleanSearchTerm() in lib/supabase/filter-pattern.ts, now cleans every search term that goes into an .or() filter: it removes , ( ) " \ and the LIKE wildcards % _ *, trims and caps at 100 characters. containsPattern() builds on it.
  • Three local sanitizers were replaced by it: song search API (sanitizePostgrestFilter), user repository (sanitizeSearchQuery) and the Song-of-the-week song search.
  • Cal.com e-mail lookups already used two .eq() queries (on dev); they now have a unit test proving an address with , and ) matches no other profile and marks no one else as a parent.
  • Dots are no longer stripped: inside an ilike value they are text, so searching Mr. Brightside or an e-mail works.
