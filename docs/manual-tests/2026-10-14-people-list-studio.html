People list in the Claude Design "Studio" style

2026-10-14 · branch fix/walkthrough-review-11-people-list

What changed

  • Each row uses the student's own avatar colour instead of a gray disc.
  • Students show level, repertoire size and, when practice tracking is on, "ćwiczenia dziś / N d temu / jeszcze bez ćwiczeń" with a health dot. Non-students keep their e-mail.
  • Phones: search on top, the three selects under "Filtry · n"; roles and join date columns only from md up; the resend link sits under the name instead of truncating it.
  • The filter fold is now one shared component (components/shared/FiltersDisclosure.tsx) used by Songs and People.
  • Repertoire size and practice recency come from one extra query per page (getStudentActivity).

How to test

  1. Demo teacher, Polish, 390 px: /dashboard/users. Four coloured rows with "N utworów · ćwiczenia …"; "WYŚLIJ PONOWNIE" under the name for students who never signed in.
  2. Search "Maja": the list narrows. Open "Filtry", pick a role: the button reads "Filtry · 1".
  3. 1440 px: search, the three selects in a row, role and join-date columns, edit/resend on the right.
  4. Admin: teachers and admins show their e-mail in the second line.
  5. With practice features off (production default) no "ćwiczenia" text and no dot appear.
