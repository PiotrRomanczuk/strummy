Student views polish

Created 2026-11-24. Refs #1180 (student items only). Checked on the dev stack with the dev student account, English and Polish, 1440 px and 375 px.

What changed

  1. Dashboard. With no assigned work the read-out shows 20 min instead of 20/0 min (desktop and phone). Streak unit and "days to next badge" use ICU plurals (day/days, dzien/dni). Weekday initials come from messages (Polish: P W Ś C P S N). The hidden page title is translated ("Pulpit").
  2. Unclosed past lesson. The student sees "Awaiting confirmation" / "Czeka na potwierdzenie" in a neutral colour on the list (desktop, phone, side panel) and the lesson page (desktop, phone). Teacher and admin views still say Overdue. The status column of the desktop list was widened so the longer label is not clipped.
  3. Theory shows 0 courses. By design, not a bug: the RLS policy tc_select_student only returns published courses that have a row in theoretical_course_access for the student, and the course in question has no access rows. No DB change. The empty state now says the teacher adds the student to a course.
  4. Calendar. A student keeps the month view of their own lessons; the integration cards (Google Calendar, Spotify), the connect prompt and the integrations query are staff-only.

How to test manually

  1. Sign in as the dev student; open /dashboard, then add ?lang=pl. Check the weekday letters and the streak unit. Log practice with nothing assigned: the read-out shows only minutes.
  2. Open /dashboard/lessons and a past scheduled lesson: label "Awaiting confirmation", not Overdue. Sign in as the teacher: the same lesson still says Overdue.
  3. Open /dashboard/theory as the student: explanatory empty state. As the teacher, add the student under course access: the course appears.
  4. Open /dashboard/calendar as the student: lessons only.
