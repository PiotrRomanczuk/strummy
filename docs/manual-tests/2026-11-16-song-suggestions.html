AI proposals for genre, level and artist (SNG-15) — manual test

Date: 2026-11-16 · Branch: feature/song-suggestions (stacked on #1116) · Tested on: the local Supabase stack on the Mac (StrummyLocal), admin account, Polish locale · Migration: 20261116120000_song_suggestions.sql (additive), applied to the local stack only.

What was done

  • Proposals, never direct writes. A model proposes a genre (only from the canonical list), a difficulty level or a missing artist. Proposals are stored in song_suggestions (admin-only RLS, one open proposal per song and field) and reach songs only when an admin accepts them in Repertoire Stats → Data quality — one by one, or every proposal at 80% confidence or more after a confirmation. A field filled meanwhile turns the proposal stale; who decided and when is kept.
  • The app never calls a model (decision 2026-11-16). Proposals come from scripts/backfill/2026-11-song-suggestions.ts on a home machine: --model claude runs Claude Code headless (claude -p with no tools, MCP servers, settings or slash commands, from the temp directory — about 600 tokens a call instead of 576k), --model local uses the Ollama host. Dry run by default; --commit saves; anything but localhost needs --remote. The model sees titles, artists and chords, nothing about students. Answers outside the allowed values, unknown songs and “unknown” artists are dropped.
  • Bulk fill from the recordings (SNG-14): one confirmed click writes all 164 values into empty fields.
  • The fix queue gets an “AI proposals” entry and the command to generate them.

How to test

  1. Apply the migration to the stack you test on; run npx tsx scripts/backfill/2026-11-song-suggestions.ts --field all --model claude --dry-run, then with --commit.
  2. Open Repertoire Stats → Data quality → “AI proposals”: each song shows the proposal, its confidence, the reason and the source.
  3. Accept one: the song gets the value, the score rises, the proposal disappears. (Tested on “Hammer Falls Down”: genre Hard Rock saved, score 44 → 52; restored by hand.) Reject one: only the decision is recorded.
  4. Fill the field in the song editor, then accept its proposal: “The field was filled meanwhile”.
  5. Bulk: “Accept AI proposals from 80%” and “Enter everything from the recordings” both ask before saving.
